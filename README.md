# BFUA(4W) — Bwiki File Upload Assistant (for Wonderia)

和deepseek一起搞的一个简易的GUI小程序，使用`mwclient` 库向 BWiki 的 **Wonderia** wiki（`https://wiki.biligame.com/wonderia`）
上传文件。

参考：
- <https://wiki.biligame.com/wonderia/api.php>
- <https://wiki.biligame.com/tools/%E5%9F%BA%E4%BA%8EPython%E7%9A%84API%E7%A4%BA%E4%BE%8B>

本程序需要需要用到自己的**SSESDATA**

常见问题：善用AI工具。
